# JASA GFM: models with and without node intercepts

Symmetric generalized factor models for Gaussian, Poisson, Logit and Probit
networks. Choose a model and run its commands from that model's folder.

| Model | Linear predictor | Start here |
| --- | --- | --- |
| Without intercepts | `Theta_ij = u_i' Lambda u_j` | [without_intercept](without_intercept/README.md) |
| With node intercepts | `Theta_ij = alpha_i + alpha_j + u_i' Lambda u_j` | [with_intercept](with_intercept/README.md) |

Both folders use `R/`, `simulations/`, `plots/`, `docs/` and `tests/`.
Numerical functions, coordinate conventions and data schemas
are model-specific. The package runs in ordinary R; local acceleration sources
are excluded.

## Simulations and figures

Each model README links to its fitting and simulation instructions. The
no-intercept simulation notebook starts a full simulation by default; use its
configuration-only example to inspect settings before running it.

| Saved-output figures | Notebook |
| --- | --- |
| Without intercepts: summary QQ, sample-size comparisons and all-node figures | [plot_figures.Rmd](without_intercept/plots/plot_figures.Rmd) |
| Without intercepts: individual QQ and Lambda histograms | [plot_individual.Rmd](without_intercept/plots/plot_individual.Rmd) |
| With intercepts: individual QQ and Lambda histograms | [plot_figures.Rmd](with_intercept/plots/plot_figures.Rmd) |

Plotting is disabled by default. These notebooks read saved replication-level
results and do not fit models or simulate networks. Theorem 2 QQ plots show
only bias-corrected statistics. The two histogram views compare ordinary and
bias-corrected estimates, and their errors relative to truth. Inputs, plotting
options and software requirements are described in each model's simulation guide.

## Saved data and reports

Simulation results, paper reports and their figures are withheld pending review
and remain in the local research workspace. They are not required to run the
code. Plotting requires matching saved replication-level files supplied by the
user or generated by a new simulation run.

## Provenance and checks

The [no-intercept provenance](without_intercept/docs/provenance.md) identifies
the upstream code snapshot. The [intercept implementation notes](with_intercept/docs/implementation_notes.md)
describe its local source and model conventions. The numerical formulas are
preserved; plotting and documentation have been updated separately.

From this repository root, verify file integrity, paths and documentation links with:

```sh
python3 tools/verify_package.py
```

See [CHECKS.md](CHECKS.md) for model checks and their scope.
`PACKAGE_MANIFEST.csv` records current file hashes; `VALIDATION.json` records
the package verification result.
