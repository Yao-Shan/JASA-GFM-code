# Source provenance

The numerical implementation is based on
[`Yao-Shan/JASA-GFM-code`, commit `4d412b7`](https://github.com/Yao-Shan/JASA-GFM-code/tree/4d412b7e6e47695f51400f374bfc594958fb1989).
Its estimation calculations, simulation settings and optimizer tolerances are
retained. Comments and documentation were shortened, and plotting functions
were updated separately. This folder is therefore not a byte-identical upstream
snapshot.

Saved outputs, paper reports and their source manifests are retained locally
pending review. They are not included in this code package. Plotting requires
separately supplied replication-level files or a newly completed simulation.

Run the model checks listed in [CHECKS.md](../../CHECKS.md).
The repository's `PACKAGE_MANIFEST.csv` records the current file hashes.
